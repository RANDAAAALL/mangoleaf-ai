# MangoLeaf AI walkthrough videos

The current video is [MangoLeafAI-walkthrough-v5.mp4](MangoLeafAI-walkthrough-v5.mp4). Earlier V2, V3, and V4 videos remain in this directory.

| Location | Contents |
| --- | --- |
| `docs/` | Walkthrough plans, narration history, and export checks. |
| `scripts/` | Python scripts for preparing footage, generating narration, building compositions, and staging reviews. |
| `assets/` | Footage, still images, narration, music, and sound effects used by the compositions. |
| `.work/v4-private/` | Local backup and restore footage required to render V4 and V5. |
| `v3.html`, `v4.html`, `v5.html` | HyperFrames compositions; timing and narration records remain beside them. |
| `.venv/`, `node_modules/` | Local dependencies; these directories are not committed. |

Start with the [V5 plan](docs/WALKTHROUGH-V5-PLAN.md) for the current video, or see the [V4 plan](docs/WALKTHROUGH-V4-PLAN.md), [V3 plan](docs/WALKTHROUGH-V3-PLAN.md), and [V2 history](docs/DEMO-REFRESH-SCRIPT.md) for earlier work. See the [script guide](scripts/README.md) for commands.

V4 and V5 display recovery codes. Their exports and the private footage are ignored by Git; review the recordings before sharing them.
