1. Do not install the full archived freeze or rerun a completed evidence notebook. Keep its historical versions and results intact.
2. Use a new isolated runtime and a separate working notebook copy. Install only the required training/export tools, selecting supported versions outside the advisory ranges.    Limit accepted decoded image formats, file bytes, and pixel dimensions before processing new inputs. A `.jpg` extension alone does not establish the actual decoded format. Verify bounded HTTPS downloads and review redirects/proxy behavior as well as hashes; a recorded hash protects known artifacts, not arbitrary new inputs.

Unused NLTK, PyJWT, and other broad environment packages should not be installed by a minimal new training setup. Reassess any required affected API before execution. `python-apt==0.0.0` is a placeholder in this freeze; inspect the real distro package if it is needed.
5. Record the new runtime, dependency audit, TensorFlow/Keras/export compatibility, finite weights, and prediction/gate parity or new evaluation results.
